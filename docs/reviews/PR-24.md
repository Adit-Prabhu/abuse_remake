## After the review: a fix that broke the course CI (found 2026-10-27)

GitHub rejected the whole workflow. The course PR then ran **no** midterm checks; only a failed

is now `github.repository == 'columbia-university-ai-games/game-dev-f26'`, and
`test_the_course_workflow_is_one_github_accepts` rejects `hashFiles` in a job-level `if`, along
with secrets and a wider permission. The test fails on the bad file.
