# Recorded demonstration

## What is already recorded

`evidence/video/scripted-level01-cp3-s0.mp4` is generated by the replay tool, not narrated. It
shows the scripted baseline on segment `level01-cp3`, seed 0, under Classic rules. A side
panel shows each decision, its result, the baseline's note and the objects it could see. The
replay re-ran the evidence trace and matched all 147 observations, every step and the final outcome. Rebuild it with:

```sh
uv run abuse-replay --trace evidence/traces/offline-v4/scripted-level01-cp3-s0.jsonl --headless \
    --video evidence/video/scripted-level01-cp3-s0.mp4
```
