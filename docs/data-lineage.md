# Data lineage

**Question:** is `data/original/` the data the 1996 game actually ran on? The vendored copy
comes from `Xenoveritas/abuse`, which descends from the abuse.zoy.org packaging. That packaging
carries community edits made between 1996 and 2008 (`COPYING.upstream` credits Justin Cassidy
and others). The pristine 1996 Lisp is not in the public-domain source release
(`historicalsource/abuse` and archive.org `abuse_pd` contain only code).

**Method:** `scripts/compare_original_data.py` downloads two original Crack dot Com releases,
checks each against a pinned SHA-256, and compares them with our copy. Level and art files are
compared byte for byte. Lisp is compared definition by definition, ignoring comments and layout.
Label: `observed` (re-run the script to reproduce).

## What it shows

1. **`levels/level01.spe` is byte-identical** to both the 1995 shareware v1.01 and the 1996
   retail 2.00 file. The geometry, objects, links and lights in scope are original.
2. **The palette and every tile set used by Level 1 are identical** across all three copies.
   Our `backgrnd.spe` only adds later `palette_hires` and `color_filter_hires` entries, which we
   do not read.
3. **The Lisp matches retail 2.00**, the version that shipped with the C engine we port. Of 409
   shared definitions, 401 are identical. The 8 that differ affect Level 1 as follows:

   | Definition | Difference from 2.00 | Effect on Level 1 |
   |---|---|---|
   | `bottom_damage` (player damage) | the network-deathmatch save path only (`addon/deathmat/` became `config/`) | none: single player |
   | `def_char DARNEL` | `draw_fun` is `frabs_bottom_draw`, a wrapper that calls `bottom_draw` unless the add-on `SHLAMP_POWER` is active | none: rendering only, and that power is not in Level 1 |
   | `ant_tints` | two extra tint entries (indices 11 and 12) | none: every Level 1 ant has `aitype` 0 or 1 |
   | `ant_cache`, `flyer_ai`, `jug_ai`, `train_ai`, `dfris_ai` | not used by Level 1 objects | none |

   The 72 definitions found only in our copy (plasma gun, light saber, death frisbee, boss,
   flyers, extra powers, debug keys) are registered-edition or later content. No Level 1
   object uses them.
4. **The 1995 shareware Lisp is an earlier design.** 54 definitions differ from it, including
   `ANT_ROOF`, `SPRAY_GUN`, `SENSOR` and `RESTART_POSITION`. The C engine we port (from the
   public-domain release) is the 2.0-era engine; for example, it compiles `ant_ai`, `top_ai` and
   `sgun_ai` into C. So the 2.0-era Lisp is the consistent rule source.

## Decision

The rule source is the vendored Lisp, cited by file and line. For Level 1 it is equivalent to
retail 2.00 apart from the differences tabled above. The retail data is not public domain, so it
is never committed; the script downloads it only for this comparison.
