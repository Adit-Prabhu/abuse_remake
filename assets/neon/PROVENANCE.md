# Neon Protocol pixel art

Artwork: **Luis Zuno (Ansimuz)**. Downloaded 2026-10-13 from the author's OpenGameArt
submissions. All vendored PNGs and bundled licence text are unmodified copies; `manifest.json`
records their archive URL, original relative path and SHA-256. Only selected artwork is
included. No music, demo code, previews or paid add-ons are included.

| Local folder | Author's source page | Licence evidence |
|---|---|---|
| `city/` | [Warped City](https://opengameart.org/content/warped-city) | Submission lists CC0; bundled `city/public-license.txt` says public domain, free personal/commercial use |
| `city2/` | [Warped City 2](https://opengameart.org/content/warped-city-2) | Submission lists CC0; bundled `city2/public-license.txt` explicitly allows use, modification and redistribution |
| `lab/` | [Warped Sci-Fi Lab](https://opengameart.org/content/warped-sci-fi-lab) | Submission lists CC0; bundled `lab/public-license.txt` explicitly allows use, modification and redistribution |

The Warped City pack's music has separate credit requirements. No audio from these archives
is included; the game continues to synthesize sound effects. Credit to Ansimuz is retained
in the in-game title and release documentation even though artwork credit is not required.

The first Neon prototype used repository vector art. The student rejected that visual style
as flat on 2026-10-13 and directed a shaded, textured presentation closer to the depth of
the original Abuse. These artist-authored assets replace its characters and environments.
The engine, controls, collisions and Classic evaluation are unaffected by artwork selection.
Runtime cropping, nearest-neighbour scaling, flips and lighting preserve the source shading
and transparency; no generative image tool is used.
